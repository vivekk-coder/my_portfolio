# Vivek Kori - Personal Brand Website Roadmap

This document outlines the growth plan for the website to evolve from a simple portfolio to a full-fledged personal brand and utility hub.

## ✅ Phase 1: Core Foundation (COMPLETED)
- **Goal:** Establish a professional online presence.
- **Features:**
  - Modern, dark-themed UI with GSAP animations.
  - Navbar (Sticky & Responsive).
  - Hero Section ("Hi, I'm Vivek Kori" + Quick Stats).
  - About Section (Bio, Skills, Quick Info).
  - Portfolio Section (Filterable project cards).
  - Contact Section (Basic `mailto:` form + Social links).
  - Footer.
- **Tech Stack:** React, Vite, CSS, GSAP, Lucide React.

## 🚀 Phase 2: Interactivity & AI Tools (UPCOMING)
- **Goal:** Add value for visitors through live tools and improve backend functionalities.
- **Features to Add:**
  - **AI Tools Section:** A dedicated page or section for live tools (e.g., Resume Builder, QR Code Generator, Image Tools).
  - **Functional Contact Form:** Replace `mailto:` with a background email service (like EmailJS or Web3Forms) so users can send messages directly from the website without opening their email app.
  - **React Router:** Introduce routing (`react-router-dom`) if the AI tools need their own dedicated pages so the homepage doesn't get too heavy.
  - **Real Project Links:** Update the placeholder links in the Portfolio section with actual live project URLs and GitHub repositories.

## 🌟 Phase 3: Content & Expansion (FUTURE)
- **Goal:** Establish authority and offer services.
- **Features to Add:**
  - **Blog Section:** Share tutorials, coding tips, and tech articles. (May require a headless CMS like Sanity or Markdown-based blogs).
  - **Services Section:** Clearly list freelance services offered (e.g., Web Development, Java Backend, 3D Animation).
  - **Free Resources:** A downloadable section for templates, cheat sheets, or code snippets.
  - **SEO Optimization:** If blogging becomes a major focus, consider migrating from Vite (Client-Side Rendering) to **Next.js** (Server-Side Rendering) for better Google Search rankings.
