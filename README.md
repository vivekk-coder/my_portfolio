## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/vivekk-coder/my_portfolio.git
```

Go to project

```bash
cd my_portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
